# Prompting by product

Choose the guide for the output you need.

| Product | Guide | What it covers |
|---|---|---|
| Text and code | [prompting-text.md](prompting-text.md) | Model and effort selection, context, writing, extraction, coding, review, and iteration |
| Images | [prompting-images.md](prompting-images.md) | Composition, exact text, photographs, illustrations, reference edits, and visual iteration |

For speech-to-text, use [transcription.md](transcription.md). It explains audio
preparation and transcript handling; the command does not accept a prompt.

For model listings, quota, authentication, and output handling, use
[SKILL.md](../SKILL.md). These operations do not need a model prompt.
